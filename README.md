# e-GP Tender Monitor — System Notice & Access Policy

ระบบติดตามประกาศจัดซื้อจัดจ้างภาครัฐ (e-GP) และแดชบอร์ดปฏิบัติการภายใน
 operated by **บริษัท เอเชี่ยน โคดดิ้ง ซิสเท็มส์ จำกัด** (เลขทะเบียนนิติบุคคล 0105537136022)

เอกสารนี้เป็นประกาศสาธารณะเรื่อง **เจ้าของระบบ ขอบเขตข้อมูล นโยบายการเข้าถึง และช่องทางติดต่อ**
ไม่ใช่การอ้างสถานะทางกฎหมายใด ๆ — การเข้าถึงระบบของบุคคลภายนอกต้องได้รับอนุญาตเป็นลายลักษณ์อักษรจากเจ้าของระบบเท่านั้น

---

## 1. ระบบนี้ทำอะไร

| ระบบ | หน้าที่ | ที่เก็บ |
|---|---|---|
| e-GP monitor / crawl | รวบรวมประกาศจัดซื้อจัดจ้างสาธารณะ (bidinthai, govsurge, data.go.th, GLO) เพื่อคัดกรองงานที่ตรงสายสินค้า | `~/ebid/` |
| Hermes web UI | แดชบอร์ด/แชทผู้ดูแลระบบ (basic auth, tailnet เท่านั้น) | `127.0.0.1:9119` + tailnet |
| Fleet tooling | สคริปต์ดูแลเครื่องในเครือข่ายส่วนตัว (Tailscale) | `~/hermes-fleet/` |

## 2. ขอบเขตข้อมูลที่จัดเก็บ

- **ข้อมูลสาธารณะเท่านั้น**: ประกาศเชิญชวน ราคากลาง ผลผู้ชนะ และข้อมูลสัญญาที่หน่วยงานรัฐเผยแพร่
- ไม่จัดเก็บข้อมูลส่วนบุคคลของผู้ใช้งานเว็บไซต์ใด ๆ นอกเหนือจากที่ปรากฏในประกาศราชการ
- ไม่มีการข้ามมาตรการควบคุมการเข้าถึง (authentication/paywall/WAF) ของแหล่งข้อมูล
- บัญชีผู้ใช้ (vendor account) ใด ๆ ที่ใช้ในระบบ เป็นบัญชีของบริษัทเองและใช้ตามข้อกำหนดของผู้ให้บริการนั้น

## 3. นโยบายการเข้าถึง

1. เข้าถึงได้เฉพาะผู้ดูแลที่ได้รับมอบหมาย (administrator) และเจ้าของระบบ
2. ทุกช่องทางต้องมี authentication (basic auth / SSH key / tailnet identity)
3. ไม่เปิด public internet โดยไม่จำเป็น — ระบบหลักผูกกับ loopback + tailnet
4. ผู้ดูแลมีหน้าที่รักษาความลับของ credential และรายงานเหตุการณ์ผิดปกติทันที
5. การให้บุคคลภายนอกเข้าถึง ต้องมีหนังสืออนุญาตจากเจ้าของระบบ และบันทึกขอบเขต/ระยะเวลา

## 4. ช่องทางติดต่อ

- ผู้ดูแลระบบ (administrator): **adminari**
- เจ้าของระบบ: บริษัท เอเชี่ยน โคดดิ้ง ซิสเท็มส์ จำกัด
- ช่องทางติดต่อ: เปิด GitHub Issue ที่ repository นี้ (หรืออีเมลของบริษัทตามที่ประกาศบนเว็บไซต์ทางการ)
- เรื่องร้องขอข้อมูล/เพิกถอนการเข้าถึง/แจ้งลบข้อมูล: ระบุหัวข้อ "ACCESS REQUEST" หรือ "TAKEDOWN"
- ระยะเวลาตอบกลับ: ภายใน 7 วันทำการ

## 5. การเปลี่ยนแปลง
